# Xphere Marketing and Design — Master Print & Fabrication Service Checklist

**Document type:** Service Discovery Audit (client fill-in)  
**Facility:** Hybrid commercial print shop + CNC / fabrication workshop  
**Purpose:** Isolate in-house capability vs white-label vs not offered; mark CORE FOCUS revenue drivers for the Next.js website; capture size, thickness, and volume limits so site copy never over-promises.

**How to complete**

1. Tick **exactly one** of: In-House / Outsource (White-label) / Do Not Offer.  
2. Tick **CORE FOCUS** only if this SKU or process is a money-maker that must be prominent on the website (home, solutions, SEO).  
3. Fill **Max Size / Thickness / Volume** with real equipment limits (e.g. `UV roll 3.2 m`, `CNC bed 3000 × 2000 mm`, `laser 1200 × 900 mm`, `offset SRA3 / B2 / B1`, `min 500 sheets`).  
4. If in-house **and** overflow is white-labelled, tick In-House **and** note overflow in the size column (`in-house to 3.2 m; overflow to 5 m partner`).  
5. Use **Notes** only for brand names of kit, inks, or partners (optional).

**Legend**

| Column | Meaning |
| --- | --- |
| IH | In-House |
| WL | Outsource / White-label (sold under Xphere) |
| DNO | Do Not Offer |
| CORE | Primary revenue / website highlight |
| Limit | Max size / thickness / volume / colour / bed |
